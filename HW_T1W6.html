NCEA Level 3 Calculus Solutions

Step-by-step worked solutions for Complex Equations and De Moivre's Theorem.

Complex Equations

Question 1

Solve the equation $z^4 + 81k^8 = 0$, where $k$ is a real constant. Give your solution(s) in polar form in terms of $k$.

Step 1: Rearrange the equation

$$ z^4 = -81k^8 $$

We must write the right-hand side in polar form ($r \text{ cis } \theta$). The modulus $r = 81k^8$, and since it's a negative real number, the base angle is $\pi$. We add $2n\pi$ to account for multiple rotations.

$$ z^4 = 81k^8 \text{ cis } (\pi + 2n\pi) $$

Step 2: Apply De Moivre's Theorem (Fractional Powers)

$$ z = (81k^8)^{\frac{1}{4}} \text{ cis } \left( \frac{\pi + 2n\pi}{4} \right) $$ $$ z = 3k^2 \text{ cis } \left( \frac{\pi}{4} + \frac{n\pi}{2} \right) $$

Step 3: Substitute $n = 0, 1, 2, 3$ to find the 4 roots

  • $n = 0 \implies z_1 = 3k^2 \text{ cis } (\frac{\pi}{4})$
  • $n = 1 \implies z_2 = 3k^2 \text{ cis } (\frac{\pi}{4} + \frac{2\pi}{4}) = 3k^2 \text{ cis } (\frac{3\pi}{4})$
  • $n = 2 \implies z_3 = 3k^2 \text{ cis } (\frac{\pi}{4} + \frac{4\pi}{4}) = 3k^2 \text{ cis } (\frac{5\pi}{4}) \equiv 3k^2 \text{ cis } (-\frac{3\pi}{4})$
  • $n = 3 \implies z_4 = 3k^2 \text{ cis } (\frac{\pi}{4} + \frac{6\pi}{4}) = 3k^2 \text{ cis } (\frac{7\pi}{4}) \equiv 3k^2 \text{ cis } (-\frac{\pi}{4})$
Final Roots: $3k^2 \text{ cis } (\frac{\pi}{4}), \quad 3k^2 \text{ cis } (\frac{3\pi}{4}), \quad 3k^2 \text{ cis } (-\frac{3\pi}{4}), \quad 3k^2 \text{ cis } (-\frac{\pi}{4})$

Question 3

Solve the equation $z^3 + 64m^{12} = 0$, where $m$ is a real constant. Write your solution(s) in polar form, in terms of $m$.

Step 1: Rearrange and convert to polar

$$ z^3 = -64m^{12} $$ $$ z^3 = 64m^{12} \text{ cis } (\pi + 2n\pi) $$

Step 2: Apply De Moivre's Theorem

$$ z = (64m^{12})^{\frac{1}{3}} \text{ cis } \left( \frac{\pi + 2n\pi}{3} \right) $$ $$ z = 4m^4 \text{ cis } \left( \frac{\pi}{3} + \frac{2n\pi}{3} \right) $$

Step 3: Substitute $n = 0, 1, 2$

  • $n = 0 \implies z_1 = 4m^4 \text{ cis } (\frac{\pi}{3})$
  • $n = 1 \implies z_2 = 4m^4 \text{ cis } (\frac{\pi}{3} + \frac{2\pi}{3}) = 4m^4 \text{ cis } (\pi)$
  • $n = 2 \implies z_3 = 4m^4 \text{ cis } (\frac{\pi}{3} + \frac{4\pi}{3}) = 4m^4 \text{ cis } (\frac{5\pi}{3}) \equiv 4m^4 \text{ cis } (-\frac{\pi}{3})$
Final Roots: $4m^4 \text{ cis } (\frac{\pi}{3}), \quad 4m^4 \text{ cis } (\pi), \quad 4m^4 \text{ cis } (-\frac{\pi}{3})$

Question 4

Solve the equation $z^3 + k^6i = 0$, where $k$ is a real constant. Give your solution(s) in polar form in terms of $k$.

Step 1: Rearrange and convert to polar

$$ z^3 = -k^6i $$

The complex number lies entirely on the negative imaginary axis, so the angle is $-\frac{\pi}{2}$.

$$ z^3 = k^6 \text{ cis } (-\frac{\pi}{2} + 2n\pi) $$

Step 2: Apply De Moivre's Theorem

$$ z = (k^6)^{\frac{1}{3}} \text{ cis } \left( \frac{-\frac{\pi}{2} + 2n\pi}{3} \right) $$ $$ z = k^2 \text{ cis } \left( -\frac{\pi}{6} + \frac{2n\pi}{3} \right) $$

Step 3: Substitute $n = 0, 1, 2$

  • $n = 0 \implies z_1 = k^2 \text{ cis } (-\frac{\pi}{6})$
  • $n = 1 \implies z_2 = k^2 \text{ cis } (-\frac{\pi}{6} + \frac{4\pi}{6}) = k^2 \text{ cis } (\frac{3\pi}{6}) = k^2 \text{ cis } (\frac{\pi}{2})$
  • $n = 2 \implies z_3 = k^2 \text{ cis } (-\frac{\pi}{6} + \frac{8\pi}{6}) = k^2 \text{ cis } (\frac{7\pi}{6}) \equiv k^2 \text{ cis } (-\frac{5\pi}{6})$

Question 4(d)

Solve the equation $z^3 = k^6 + k^6i$, where $k$ is a real constant.

Step 1: Convert RHS to polar

Modulus $r = \sqrt{(k^6)^2 + (k^6)^2} = \sqrt{2k^{12}} = \sqrt{2}k^6$.
Argument $\theta = \tan^{-1}(k^6/k^6) = \frac{\pi}{4}$.

$$ z^3 = \sqrt{2}k^6 \text{ cis } (\frac{\pi}{4} + 2n\pi) $$

Step 2: Apply De Moivre's Theorem

$$ z = (\sqrt{2}k^6)^{\frac{1}{3}} \text{ cis } \left( \frac{\frac{\pi}{4} + 2n\pi}{3} \right) $$ $$ z = 2^{\frac{1}{6}}k^2 \text{ cis } \left( \frac{\pi}{12} + \frac{2n\pi}{3} \right) $$

Step 3: Substitute $n = 0, 1, 2$

  • $n = 0 \implies z_1 = 2^{\frac{1}{6}}k^2 \text{ cis } (\frac{\pi}{12})$
  • $n = 1 \implies z_2 = 2^{\frac{1}{6}}k^2 \text{ cis } (\frac{\pi}{12} + \frac{8\pi}{12}) = 2^{\frac{1}{6}}k^2 \text{ cis } (\frac{9\pi}{12}) = 2^{\frac{1}{6}}k^2 \text{ cis } (\frac{3\pi}{4})$
  • $n = 2 \implies z_3 = 2^{\frac{1}{6}}k^2 \text{ cis } (\frac{\pi}{12} + \frac{16\pi}{12}) = 2^{\frac{1}{6}}k^2 \text{ cis } (\frac{17\pi}{12}) \equiv 2^{\frac{1}{6}}k^2 \text{ cis } (-\frac{7\pi}{12})$

Question 5

Find the roots of the equation $z^2 - 6z + 25 = 0$ giving your answers in the form of $x+iy$ where $x$ and $y$ are real.

Step 1: Apply the Quadratic Formula

$$ a = 1, \quad b = -6, \quad c = 25 $$ $$ z = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a} $$ $$ z = \frac{6 \pm \sqrt{(-6)^2 - 4(1)(25)}}{2} $$

Step 2: Simplify the Discriminant

$$ z = \frac{6 \pm \sqrt{36 - 100}}{2} $$ $$ z = \frac{6 \pm \sqrt{-64}}{2} $$ $$ z = \frac{6 \pm 8i}{2} $$

Step 3: Final Answers

$$ z = 3 \pm 4i $$
Final Roots: $z_1 = 3 + 4i, \quad z_2 = 3 - 4i$

Operators and De Moivre

Question 1

If $v = 4 \text{ cis } \frac{3\pi}{4}$ and $w = 6 \text{ cis } \frac{2\pi}{3}$, write the exact value of $\frac{v}{w}$ in polar form.

Step 1: Apply division rules for polar form

When dividing complex numbers in polar form, divide the moduli and subtract the arguments.

$$ \frac{v}{w} = \frac{4}{6} \text{ cis } \left( \frac{3\pi}{4} - \frac{2\pi}{3} \right) $$

Step 2: Find common denominator for the arguments

$$ \frac{v}{w} = \frac{2}{3} \text{ cis } \left( \frac{9\pi}{12} - \frac{8\pi}{12} \right) $$
Final Answer: $\frac{2}{3} \text{ cis } \left( \frac{\pi}{12} \right)$

Question 2

If $u = 12k^3 \text{ cis }(\pi)$ and $v = 2k \text{ cis }(\frac{\pi}{3})$ write the exact value of $\frac{u}{v}$ in polar form.

Step 1: Apply division rules

$$ \frac{u}{v} = \frac{12k^3}{2k} \text{ cis } \left( \pi - \frac{\pi}{3} \right) $$

Step 2: Simplify

$$ \frac{u}{v} = 6k^2 \text{ cis } \left( \frac{3\pi}{3} - \frac{\pi}{3} \right) $$
Final Answer: $6k^2 \text{ cis } \left( \frac{2\pi}{3} \right)$

Question 3

If $u = m \text{ cis }(\frac{3\pi}{10})$ write $u^5$ in the form $a+bi$, where $a$ and $b$ are both real numbers, giving your answer in terms of $m$.

Step 1: Apply De Moivre's Theorem

$$ u^5 = (m \text{ cis } (\frac{3\pi}{10}))^5 $$ $$ u^5 = m^5 \text{ cis } \left( 5 \times \frac{3\pi}{10} \right) $$ $$ u^5 = m^5 \text{ cis } \left( \frac{15\pi}{10} \right) = m^5 \text{ cis } \left( \frac{3\pi}{2} \right) $$

Step 2: Convert to rectangular ($a+bi$) form

Recall that $\text{cis }(\theta) = \cos(\theta) + i\sin(\theta)$.

$$ u^5 = m^5 \left( \cos(\frac{3\pi}{2}) + i\sin(\frac{3\pi}{2}) \right) $$ $$ u^5 = m^5 \left( 0 + i(-1) \right) $$ $$ u^5 = -m^5i $$
Final Answer: $a = 0, \quad b = -m^5 \implies -m^5i$

Question 4

If $z = m \text{ cis }(\frac{n\pi}{5})$, where $m$ and $n$ are positive real constants, then find $z^{15}$ giving your answer in polar form, in terms of $m$ and $n$.

Step 1: Apply De Moivre's Theorem

$$ z^{15} = \left( m \text{ cis } (\frac{n\pi}{5}) \right)^{15} $$ $$ z^{15} = m^{15} \text{ cis } \left( 15 \times \frac{n\pi}{5} \right) $$

Step 2: Simplify the argument

$$ z^{15} = m^{15} \text{ cis } (3n\pi) $$
Final Answer: $m^{15} \text{ cis } (3n\pi)$
