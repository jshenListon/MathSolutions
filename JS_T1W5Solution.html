Question 1: Resistors in Parallel

The harmonic mean formula for two resistors in parallel is $R_{combined} = \frac{R_{1} \times R_{2}}{R_{1} + R_{2}}$

a) Prove that if two identical resistors ($R$) are connected in parallel, the combined resistance is $\frac{R}{2}$.

Let both resistors be identical, so $R_1 = R$ and $R_2 = R$. Substitute these into the formula:

$$R_{combined} = \frac{R \times R}{R + R} = \frac{R^2}{2R}$$

By cancelling out one $R$ from the numerator and the denominator, we get:

$$R_{combined} = \frac{R}{2}$$
b) Prove that if we connect three identical resistors in parallel, the total resistance is $\frac{R}{3}$.

We can solve this by combining the resistors in steps using the conclusion from part (a).

  1. Combine the first two resistors ($R_1$ and $R_2$). Their equivalent resistance is $R_{1,2} = \frac{R}{2}$.
  2. Treat this equivalent resistance $R_{1,2}$ as a single resistor and connect it in parallel with the third identical resistor, $R_3 = R$.
  3. Apply the parallel resistance formula again:
$$R_{total} = \frac{R_{1,2} \times R_3}{R_{1,2} + R_3} = \frac{\left(\frac{R}{2}\right) \times R}{\left(\frac{R}{2}\right) + R}$$ $$R_{total} = \frac{\frac{R^2}{2}}{\frac{3R}{2}}$$ $$R_{total} = \frac{R^2}{2} \times \frac{2}{3R}$$
$$R_{total} = \frac{R}{3}$$
c) Find a general formula for the total resistance of three different resistors $R_1$, $R_2$, and $R_3$ connected in parallel.

We follow the same two-step process, but keep the variables distinct.

  1. First, combine $R_1$ and $R_2$: $$R_{1,2} = \frac{R_1 R_2}{R_1 + R_2}$$
  2. Next, combine $R_{1,2}$ in parallel with $R_3$:
$$R_{total} = \frac{\left(\frac{R_1 R_2}{R_1 + R_2}\right) \times R_3}{\left(\frac{R_1 R_2}{R_1 + R_2}\right) + R_3}$$

To simplify this complex fraction, multiply the numerator and the denominator by $(R_1 + R_2)$:

$$R_{total} = \frac{R_1 R_2 R_3}{R_1 R_2 + R_3(R_1 + R_2)}$$

Expanding the denominator yields the final general formula:

$$R_{total} = \frac{R_1 R_2 R_3}{R_1 R_2 + R_1 R_3 + R_2 R_3}$$

Question 2: ISBN Validation

An ISBN is valid if the 10th digit is the remainder of the weighted sum of the first 9 digits divided by 11.

a) Is the string 038696617X an ISBN?

To verify the ISBN, we calculate the weighted sum of the first 9 digits and find its remainder when divided by 11.

Substitute the digits $(0, 3, 8, 6, 9, 6, 6, 1, 7)$ into the sum formula:

$$\text{Sum} = 1(0) + 2(3) + 3(8) + 4(6) + 5(9) + 6(6) + 7(6) + 8(1) + 9(7)$$ $$\text{Sum} = 0 + 6 + 24 + 24 + 45 + 36 + 42 + 8 + 63 = 248$$

Divide 248 by 11 to find the remainder:

$$248 \div 11 = 22 \text{ with a remainder of } 6$$ (Since $22 \times 11 = 242$, and $248 - 242 = 6$)

The remainder is 6, so the 10th digit should be 6. However, the string ends in 'X' (which represents a remainder of 10). Because $6 \neq 10$, this string is NOT a valid ISBN.

b) The ISBN reads 0321149Z20, where 'Z' is unknown. Find Z.

Setup the sum with the known digits ($x_1=0, x_2=3, x_3=2, x_4=1, x_5=1, x_6=4, x_7=9, x_8=Z, x_9=2$):

$$\text{Sum} = 1(0) + 2(3) + 3(2) + 4(1) + 5(1) + 6(4) + 7(9) + 8(Z) + 9(2)$$ $$\text{Sum} = 0 + 6 + 6 + 4 + 5 + 24 + 63 + 8Z + 18 = 126 + 8Z$$

Since the 10th digit is 0, the total sum $(126 + 8Z)$ must yield a remainder of 0 when divided by 11 (it must be a perfect multiple of 11).

Let's find the remainder of 126 divided by 11: $126 = (11 \times 11) + 5$. This means $5 + 8Z$ must be a multiple of 11.

Because $Z$ must be a single digit between 0 and 9, we can test values. If we test $Z = 9$:

$$5 + 8(9) = 5 + 72 = 77$$

Since 77 is a multiple of 11 ($11 \times 7$), the missing digit is:

$$Z = 9$$
c) Show that if the 4th and 5th digits (which are different) are transposed, the resulting string is not an ISBN.
  1. Let the original correct sum be $S = x_1 + 2x_2 + 3x_3 + 4x_4 + 5x_5 + \dots + 9x_9$. The remainder of $S \div 11$ gives the 10th digit.
  2. If the 4th and 5th digits are transposed, the sequence stays exactly the same except the new 4th digit is $x_5$ and the new 5th digit is $x_4$.
  3. The new sum is $S_{new} = x_1 + 2x_2 + 3x_3 + 4x_5 + 5x_4 + \dots + 9x_9$.
  4. Let's find the difference between the new sum and the old sum:
    $$S_{new} - S = (4x_5 + 5x_4) - (4x_4 + 5x_5) = x_4 - x_5$$
  5. For the transposed string to accidentally still be a valid ISBN (sharing the exact same 10th check digit), the new sum $S_{new}$ must leave the same remainder as $S$ when divided by 11. Mathematically, this means their difference $(x_4 - x_5)$ must be a multiple of 11.
  6. Since $x_4$ and $x_5$ are single digits from 0 to 9, the absolute maximum difference between them is 9. The only way their difference can be a multiple of 11 is if the difference is exactly 0 (which means $x_4 = x_5$).
  7. However, the problem explicitly states that the 4th and 5th digits are different. Therefore, $x_4 - x_5 \neq 0$, meaning the difference cannot possibly be a multiple of 11.
  8. Because the difference isn't a multiple of 11, the sum's remainder permanently changes, meaning the original 10th digit will no longer match, thus invalidating the ISBN.
